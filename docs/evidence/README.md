# Recorded verification evidence

The epic directories contain historical delivery transcripts, reports, and source manifests. Their timestamps, outcomes, and recorded source hashes describe the revisions named in those files; they are not verification results for today's working tree.

Document filename references have been normalized to the current `output/{yyyy-mm-dd-hh-mm-ss}-content.md` convention. A timestamp placeholder denotes a historical path whose run start time was not captured in that excerpt. References to the former saved example use its original UTC start time, `2026-10-01T19:56:05Z`. That example workspace was deleted during the requested run cleanup. Historical manifests retain its content hash for provenance; they cannot verify the cleaned working tree. Other historical hashes have not been regenerated.

The `content-writer/` directory contains the current CLI and API guide captures. Its scope and fixture limitations are recorded alongside the responses.
